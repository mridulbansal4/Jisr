`apps/web` is a Next.js 16.4 App Router PWA in TypeScript 5.9 with Tailwind CSS 4.3, next-intl 4.15 (Arabic and Urdu RTL), shadcn/ui and Recharts. It serves four role views (person, clinician/coordinator, programme, Judge Mode), about 28 screens in total ([UI_SPEC §0](../02-design/UI_SPEC.md)).

## 2. Routing and role guards

- Locale prefix always present (`/ar/...`). `middleware.ts` (next-intl) negotiates locale from cookie → `Accept-Language` → `NEXT_PUBLIC_DEFAULT_LOCALE` (`ar`).
- Staff and programme routes exist in `ar` and `en`; `ur` falls back to `en` there (UI_SPEC).
- Role guard: a server component layout per area (`staff/layout.tsx`, `programme/layout.tsx`) checks the token's role and redirects to `/judge` (demo) or `/` otherwise. The server still enforces scopes; guards are UX only.
- `help` (S-06) and the crisis numbers need **no token** and render statically.

## 3. Data fetching and state

| Concern | Approach |
|---|---|
| Server state | TanStack Query 5 in client components; RSC `fetch` with `cache: 'no-store'` for first render of PHI pages |
| Types | `pnpm gen:api` → `openapi-typescript ../../packages/contracts/openapi.yaml -o lib/api/schema.d.ts`; CI fails if the generated file is stale |
| Runtime validation | Zod on critical responses (API-03, API-04, API-24) so a malformed crisis response still shows the crisis screen |
| Episode status | Poll API-05 every 10 s on the result/step screens (so a late M-02 raise or staff action appears); every 15 s on staff queues (API-11) |
| Mutations | Always send `Idempotency-Key` (uuid per user action); retry on network error with the same key |
| Local UI state | React state + one context for `discreetMode`, `readAloud`, `role`; no Redux |
| Auth token | Memory first, mirrored in `sessionStorage` (cleared on quick-exit and tab close). Never `localStorage` |
| Forms | React Hook Form + Zod resolver (only where forms exceed 3 fields: settings, consent, contact attempt) |

## 4. Safety-critical UI patterns

1. **Crisis first, client-side too.** S-03 (item 9) and S-04 run `lib/crisis/lexicon.ts` locally as the person types/selects. A local hit routes immediately to S-06 (the server confirms via API-02/03/04; the client check can only add a safety screen, never remove one).
2. **Crisis response handling.** Any API response with `crisis: true`, or a `423 LOCKED_CRISIS`, or a network failure during API-03 → render S-06 with numbers. Fail-closed in the UI as on the server.
3. **LLM lock.** On RED, the AI-drafted panel component (`AiDrafted`) renders nothing but a "locked for your safety" note.
4. **Three content types are visually distinct** (CLAUDE.md): `Observed` (answers, imported results), `Calculated` (scores, step, RCI with rule IDs), `AiDrafted` (explanations, with "AI-assisted wording, checked against your scores" label and a "see the plain version" toggle to the template).
5. **Quick exit (F-14).** Fixed button; on tap: clear `sessionStorage`, replace history (`location.replace`) with the neutral destination (S-50), so Back does not return.
6. **Discreet mode.** Neutral tab title ("Health app"), neutral manifest name for installed PWA, no badge API calls, neutral notification text.
7. **No consent, no LLM.** If `ai_drafted_summaries` is off, the result screen shows templates only and says so.

## 5. Internationalisation and RTL

- `next-intl` 4.15 with ICU messages in `messages/{ar,en,ur}.json`; lint rule forbids JSX string literals outside `messages`.
- `<html lang dir>` from locale (`ar`, `ur` → `rtl`). Tailwind logical utilities only (`ms-*`, `me-*`, `ps-*`, `text-start`); a lint rule bans `ml-*`, `mr-*`, `left-*`, `right-*` in person screens.
- Fonts: Noto Naskh Arabic / Noto Sans Arabic, Noto Nastaliq Urdu, Inter (Latin), self-hosted via `next/font` with `display: swap` and per-locale subsetting ([DESIGN_SYSTEM](../02-design/DESIGN_SYSTEM.md)).
- Numbers: Western digits by default in all locales (clinician readability); dates `Asia/Dubai`.
- Read-aloud (F-20): `window.speechSynthesis` with locale voice if present; hidden if no voice for `ur`/`ar` on the device.

## 6. Offline and PWA

See [MOBILE.md](MOBILE.md) for the full rationale.
- Serwist (`@serwist/next` 9.5.15) generates the service worker from `app/sw.ts`.
- **Precache:** app shell, fonts, `messages/*`, `/[locale]/help`, crisis lines, compiled lexicon (~30 KB).
- **Runtime caching:** static assets `StaleWhileRevalidate`; **never** cache `/v1/*` (PHI, `no-store`).
- **Offline queue:** screening answers (API-02) are queued in IndexedDB with their idempotency keys and replayed on `online`.
- `NEXT_PUBLIC_OFFLINE_DEMO=true`: demo-day fallback that serves bundled synthetic seed responses if the API is unreachable (never in production builds).

## 7. Performance budget

Targets are defined in [PERFORMANCE.md](PERFORMANCE.md). Frontend rules that make them reachable:
- Person routes are server components by default; client components only for interactive question cards, charts and polling.
- Initial JS for person routes ≤ 170 KB gzip; S-06 crisis route ≤ 50 KB and no client data fetch to show numbers.
- Recharts loaded with `next/dynamic` on programme routes only.
- Images: none required on person routes except a small SVG logo; icons as inline SVG (lucide subset).
- Lighthouse CI on `/ar`, `/ar/screen/demo/q/1`, `/ar/help`, `/ar/episode/demo/result` with mobile preset.

## 8. Folder and component conventions

- One component per file, PascalCase; hooks `useX` in `lib/hooks`.
- Server components by default; add `'use client'` only when needed and keep those leaf-level.
- Props typed from `schema.d.ts` types (`components['schemas']['Episode']`), never hand-written duplicates.
- Every interactive element has an accessible name from `messages`; touch targets ≥ 44 × 44 px ([ACCESSIBILITY](../02-design/ACCESSIBILITY.md)).
- Analytics: `track('screen_viewed', {screen, locale, role})` via `lib/analytics.ts` → API-29. The client mirrors the server allow-list and drops any other key; never send scores, answers or text.
- Tests next to code (`*.test.tsx`) with Vitest + Testing Library + MSW; RTL snapshot per locale for S-05, S-06, S-07, S-24.
