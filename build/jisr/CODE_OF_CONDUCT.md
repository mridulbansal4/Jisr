# Code of Conduct
We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and inclusive; no harassment, discrimination or personal attacks; assume good intent. This project deals with mental health, so speak about it without stigma, in issues and in code comments too.

Report concerns to the project maintainers listed in [TEAM](docs/08-project/TEAM.md). Maintainers may remove content or contributors who violate this code.
